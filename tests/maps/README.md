# Map compatibility regression

The showcase also includes [a real OpenStreetMap railway composition](../../Examples/MotionShowcase/Railway/README.md),
with Tokyo roads, the entire Yamanote track loop and all 30 bilingual station labels. `make maps-visual`
checks that composition against Remotion on both backends, in addition to these synthetic image fixtures.
The Yamanote composition uses live/cached street tiles and a zooming camera that follows the train;
its first render needs tile access. The image fixtures below remain offline.

Run `make maps-visual` on macOS ARM64. `make ci` runs this gate on every push;
`npm test --prefix tests` also checks the native compiler's map-package boundary.
Reports and comparison PNGs go to `tests/reports/maps/` and the existing CI artifact.

The two compositions exercise supported image workflows:

- `OpenStreetMapTiles`: six local raster tiles, clipped viewport, frame-driven pan, and animated marker.
- `MapKitSnapshot`: a prepared raster snapshot with a frame-driven marker overlay.

All PNGs are synthetic, authored test patterns generated by `generate-assets.mjs`.
They contain no OpenStreetMap or Apple imagery and do **not** prove provider connectivity,
SDK initialization, authorization, geographic accuracy, or map attribution compliance.
Each run renders references with the pinned Remotion and Chrome, compares CPU and GPU
native output with the existing 0.3% changed-pixel gate, and requires exact native repeats.
The expected marker position guards against empty frames. These live comparisons are
separate from the reviewed core goldens and do not regenerate any golden files.

Interactive Leaflet / React Leaflet and MapKit JS are not currently integrated with
MotionSwift's JavaScriptCore native renderer. The package tests verify rejection from
the shipped vendor graph; they are not evidence of a browser fallback. No MapKit native
snapshot API is implemented by these tests either.

For real projects, prepare provider-authorized imagery outside the render, retain all
required attribution in the exported video, and use `Img` for deterministic rendering.
MapKit JS needs an Apple Maps token: [Apple authorization documentation](https://developer.apple.com/documentation/MapKitJS/creating-a-maps-token).
Browser map animation also needs to synchronize map readiness with rendering:
[Remotion map guidance](https://www.remotion.dev/docs/maps).

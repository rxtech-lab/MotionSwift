# Open-Source Remotion Examples

Twelve MIT-licensed compositions from four public GitHub repositories, bundled for offline SwiftUI preview, visual editing, MP4 export, and cross-engine Remotion vs. MotionSwift benchmarking:

1. **`Alexwtlf/agentic-product-demo`** (`907b7b7`) — `ProductDemo` (`Acme Studio`)
2. **`zz41354899/SwiftClip`** (`1ab3903`) — `DynamicIsland`, `MetricDashboard`, `DataViz`, `CountdownTimer` (all four upstream `.tsx` files run **100% unmodified**)
3. **`RenderComp/free-remotion-templates`** (`f648980`) — `BarChartAnim` (**100% unmodified**), `LineChartAnim`, `LowerThirdGlassCard`, `BokehCircles`
4. **`lifeprompt-team/remotion-scenes`** (`02c7a84`) — `DataGauge`, `BackgroundAurora`, `ShapeCircularProgress`

See [`provenance.json`](provenance.json) for per-composition commit SHAs, preview frames, and subset adaptation notes, and [`THIRD-PARTY-LICENSES.txt`](THIRD-PARTY-LICENSES.txt) for full MIT copyright and permission notices.
